# Nuvio JJJ

A curated collection of 48 scrapers for English, Spanish Latino, French, Japanese, and other supported languages in the Nuvio streaming application.

## Installation

1. Open Nuvio app
2. Go to Settings > Plugings
3. Add this repository URL:
   ```
   https://raw.githubusercontent.com/JaredJomar/Nuvio-JJJ/refs/heads/main/manifest.json
   ```
4. Enable the scrapers you want to use
